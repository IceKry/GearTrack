# GearTrack
**GearTrack es una plataforma de gestión y CRM diseñada para talleres mecánicos y centros de servicio automotriz.**

**Permite administrar clientes, vehículos, órdenes de trabajo y técnicos, además de automatizar el seguimiento de mantenimientos preventivos mediante alertas de servicio.**


## Características principales

- **Gestión de clientes y vehículos**
- **Control de Órdenes de Trabajo**
- **Trazabilidad e Historial Técnico**
- **Asignación de Técnicos**
- **Sistema de Alertas de Mantenimiento**
- **Dashboard de Métricas**
